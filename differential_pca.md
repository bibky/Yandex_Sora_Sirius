# Дифференциальный PCA: подготовка данных для differential ML

Материал рассчитан примерно на 5 минут выступления.

## 1. С какими данными работаем

Мы симулируем методом Монте-Карло **m** сценариев рынка. В каждом сценарии есть **n** входных переменных, например цены n акций в момент $T_1$.

| Таблица | Размер | Что в строке i |
|---|---|---|
| $X$, входы | m × n | состояние рынка в момент $T_1$ |
| $Y$, метки | m × 1 | выплата инструмента в момент $T_2$ |
| $Z$, производные | m × n | чувствительность выплаты к каждому входу в этом сценарии |

Производные $Z$ считаются по каждой траектории отдельно с помощью AAD. Нейросеть учится и на значениях $Y$, и на производных $Z$. Перед обучением данные нужно привести в порядок.

## 2. Обычный PCA, коротко

Обычный PCA раскладывает ковариационную матрицу входов $\frac{1}{m}X^TX$ (размер n × n) на собственные векторы и собственные значения. После преобразования столбцы входов не коррелируют между собой и имеют дисперсию 1. Направления с нулевым разбросом (постоянные или дублирующие входы) выбрасываются.

Сети это помогает, но у PCA есть ограничение: он смотрит только на $X$ и ничего не знает про $Y$. Он находит направления, вдоль которых входы сильно меняются. Влияют ли эти направления на выплату, он не проверяет. Отсюда три следствия:

- он не убирает входы, которые на выплату не влияют;
- он почти не снижает размерность, если входы не дублируют друг друга;
- агрессивный порог отсечения опасен, можно выбросить важный вход с малым разбросом.

## 3. Идея дифференциального PCA

Сделаем ту же процедуру, но с таблицей производных $Z$ вместо таблицы входов $X$.

Берём данные после обычного PCA и считаем матрицу

$$\frac{1}{m} Z^T Z = Q E Q^T .$$

- $\frac{1}{m}Z^TZ$ имеет размер n × n. Элемент (j, k) это среднее по сценариям произведение производной по входу j на производную по входу k.
- $Q$ (n × n): каждый столбец это направление в пространстве входов, то есть комбинация входов.
- $E$ (n × n, диагональная): $E_{jj}$ это средний квадрат чувствительности выплаты к движению вдоль направления j. Статья называет эту величину **релевантностью**.

Дальше поворачиваем и входы, и производные одной матрицей: $\tilde X = XQ$, $\tilde Z = ZQ$. Направления с малым $E_{jj}$ выбрасываем. Если осталось $n_3$ направлений, новые таблицы имеют размер m × $n_3$.

Сравнение двух процедур:

| | Обычный PCA | Дифференциальный PCA |
|---|---|---|
| Что раскладываем | входы $X$ | производные $Z$ |
| Большое собственное значение | входы сильно меняются вдоль направления | выплата сильно реагирует на движение вдоль направления |
| Нулевое собственное значение | вход постоянный или лишний | вход не влияет на выплату |
| Порог отсечения | только численный ноль | можно ставить $10^{-4}$ и выше |

## 4. Почему отсекать можно смело

После обычного PCA у каждого входа дисперсия 1, у меток тоже. Поэтому производная измеряется в «стандартных отклонениях выплаты на одно стандартное отклонение входа».

Пусть $E_{jj} = 10^{-4}$. Тогда типичная чувствительность равна $\sqrt{10^{-4}} = 10^{-2}$. Чтобы сдвинуть выплату на одно стандартное отклонение, вход должен сдвинуться на $1 / 10^{-2} = 100$ своих стандартных отклонений. Такого в данных не бывает, значит, направление можно убрать без потери информации.

По этой же причине обычный PCA должен идти первым: без него производные по разным входам измерены в разных единицах, и общий порог не имеет смысла.

## 5. Примеры

### Пример 1. Корзинный опцион

Опцион на корзину из трёх акций с весами $a = (0{,}5;\ 0{,}3;\ 0{,}2)$. Выплата равна $(S_{T_2}\cdot a - K)^+$.

Строка производных в каждом сценарии бывает двух видов:

- опцион в деньгах: $Z = (0{,}5;\ 0{,}3;\ 0{,}2)$, то есть веса корзины;
- опцион вне денег: $Z = (0;\ 0;\ 0)$.

Все ненулевые строки направлены одинаково. Если доля сценариев в деньгах равна $q$, то $\frac{1}{m}Z^TZ = q\,aa^T$. У такой матрицы одно ненулевое собственное значение $q\|a\|^2$, и его собственный вектор направлен вдоль $a$.

Считаем: $\|a\|^2 = 0{,}25 + 0{,}09 + 0{,}04 = 0{,}38$. При $q = 0{,}5$ собственное значение равно $0{,}5 \cdot 0{,}38 = 0{,}19$. Два остальных равны нулю.

Результат: размерность падает с 3 до 1, и единственный оставшийся фактор совпадает с весами корзины. Алгоритм нашёл это только по данным, формулу выплаты ему не сообщали. Обычный PCA оставил бы все три направления.

### Пример 2. Тихая акция

Есть 500 акций. Одна из них, назовём её XXX, почти не колеблется и не коррелирует с остальными. При этом в портфеле главная позиция открыта именно по XXX.

- Обычный PCA с агрессивным порогом выбросит XXX: разброс вдоль неё мал.
- Дифференциальный PCA её сохранит: производные выплаты по XXX велики, значит, релевантность высокая.

Этот пример показывает, почему размерность нужно снижать по релевантности, а не по разбросу входов.

### Пример 3. Дельта-хеджированный колл

Обычный риск-отчёт усредняет производные по сценариям. Для колла с дельта-хеджем средняя дельта равна нулю, и по отчёту кажется, что акция на позицию не влияет.

В отдельных сценариях производные ненулевые: где-то положительные, где-то отрицательные. Дифференциальный PCA использует средний **квадрат** производных, знаки не сокращаются, и акция остаётся релевантным фактором. Потраекторные производные содержат больше информации, чем их среднее.

## 6. Одна оговорка

Матрица $\frac{1}{m}Z^TZ$ считается без вычитания среднего. Постоянная производная означает линейную зависимость выплаты от входа, и такой вход нужно сохранить. Если среднее вычесть, останутся только нелинейные факторы.

## 7. Весь алгоритм по шагам

| Шаг | Что делаем | Размер входов |
|---|---|---|
| 1. Нормировка | центрируем $X$, нормируем $Y$, делим $Z$ на $\sigma_Y$ | m × n |
| 2. Обычный PCA | делаем входы некоррелированными с дисперсией 1, убираем лишние | m × $n_2$ |
| 3. Дифференциальный PCA | поворачиваем к осям релевантности, убираем невлияющие | m × $n_3$ |
| 4. Обучение | учим сеть на преобразованных данных | |
| 5. Предсказание | новый вход проходит шаги 1–3, ответ сети переводим в исходные единицы | |

## 8. Итог

- Дифференциальный PCA это PCA по матрице производных.
- Он находит направления, от которых выплата действительно зависит, и упорядочивает их по силе влияния.
- Размерность снижается безопасно, потому что отбрасываются только направления с нулевой чувствительностью.
- Помимо подготовки данных для сети, метод полезен сам по себе: он извлекает факторы риска сделки из симулированных данных.
